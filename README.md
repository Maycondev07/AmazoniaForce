# 🌿 Amazônia Force

Site de venda de produtos pneumáticos — Amazônia Force.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 📂 Estrutura do Projeto

```
AmazoniaForce/
├── Assets/          # Imagens e recursos visuais
├── Routes/          # Páginas secundárias
├── Index.html       # Página principal
├── Style.css        # Estilos globais
└── Script.js        # Lógica e interatividade
```

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Maycondev07/AmazoniaForce.git
   ```
2. Abra o arquivo `Index.html` no navegador.
